# Fontes verificáveis

- Microsoft, [Master File Table](https://learn.microsoft.com/en-us/windows/win32/fileio/master-file-table): registros, atributos e zona da MFT.
- Microsoft, [Master File Table — Developer Notes](https://learn.microsoft.com/en-us/windows/win32/devnotes/master-file-table): registros, atributos e arquivo de alocação $Bitmap.
- Microsoft, [Comparação de funcionalidades](https://learn.microsoft.com/en-us/windows/win32/fileio/filesystem-functionality-comparison): journaling de metadados, ACL, compressão, criptografia e limites comparativos.
- Microsoft, [Especificação exFAT](https://learn.microsoft.com/en-us/windows/win32/fileio/exfat-specification): objetivos e estrutura da família FAT.
- Microsoft, [NTFS overview](https://learn.microsoft.com/en-us/windows-server/storage/file-server/ntfs-overview): recursos do NTFS no Windows.
- Microsoft, [Change journals](https://learn.microsoft.com/en-us/windows/win32/fileio/change-journals): registro USN de alterações, distinto do log de recuperação.
- Microsoft, [File security and access rights](https://learn.microsoft.com/en-us/windows/win32/fileio/file-security-and-access-rights): descritores de segurança e ACL.

Consulta em 19/11/2026. Recursos e suporte variam conforme sistema operacional, versão e configuração; o desempenho depende da carga e do hardware.
